# MLIA LiteRT Converter

## Purpose

This repository packages the LiteRT / TensorFlow Lite `.tflite` converter used
by MLIA.

## Included plugins

- `tflite_to_tosa`: LiteRT / TensorFlow Lite `.tflite`-to-TOSA transformer
